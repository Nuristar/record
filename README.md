# 기록관리 표준노트 (PWA)

기록물관리 전문요원 시험과 ISO 기록관리 표준을 공부하는 웹앱입니다. 서버 없이 정적 파일만으로 동작합니다.

## GitHub Pages로 올리는 방법

1. GitHub에서 새 저장소를 만듭니다. (예: `rk-notes`)
2. 이 폴더의 파일을 **저장소 맨 위(루트)에** 모두 올립니다.
   `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`
3. 저장소의 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 저장합니다.
4. 1~2분 뒤 `https://내아이디.github.io/rk-notes/` 주소가 생깁니다.

## 폰에 설치하기

- **안드로이드 Chrome**: 주소를 열고 메뉴(⋮) → 홈 화면에 추가(또는 앱 설치).
- **아이폰 Safari**: 주소를 열고 공유 버튼 → 홈 화면에 추가.

설치하면 학습 카드, 퀴즈, 복습은 인터넷 없이도 열립니다. 번역은 인터넷이 필요합니다. (Chrome 내장 번역을 쓸 수 있는 환경이면 기기 안에서 처리됩니다.)

## 알아 둘 점

- 공개 저장소로 올리면 앱에 담긴 요약 내용도 공개됩니다. ISO 표준 원문은 들어 있지 않습니다.
- 진도, 오답, 내 문제는 폰 브라우저에만 저장됩니다. 홈 화면의 **진도 백업**으로 파일을 저장해 두세요.
- 앱을 고쳐서 다시 올릴 때는 `sw.js` 맨 위의 `V = 'rk-v1'`을 `rk-v2`처럼 바꿔야 폰에 새 파일이 반영됩니다.
- 무료 번역 서비스(MyMemory)는 하루 사용량 제한이 있습니다. 번역 화면에 이메일을 넣으면 한도가 늘어납니다. 입력한 문장이 외부 서비스로 전송되니 민감한 내용은 넣지 마세요.
- 법령 요약은 학습용 정리입니다. 시험 전에 국가법령정보센터와 국가기록원 공고로 최신 내용을 확인하세요.
